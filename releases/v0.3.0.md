Three new space-age plates: Tracking Board, inspired by GSOC's 1970 control room; Survey Sheet, after Soviet survey maps of the 1980s; and Operations, with European mission control's cyan geography and amber counters. All fifteen plates work on Groundtrack and Groundtrack Fuller.

An optional **Minute ticker** puts large two-digit minutes and a sixty-minute progress scale in a fixed panel. It works on every chart, including the whole day and scrolling world maps, independently of the existing route readout. Enable it in the settings page's Time section. Existing settings keep their appearance through the upgrade.

Satellites can show **Estimated sunlight** in the corner: SUNLIT or ECLIPSE (Earth's full shadow). This is a spherical-Earth estimate at each minute, not a visibility prediction; old orbit data still takes precedence as EL OLD. The Moon keeps its phase display.

Memory savings preserve the existing pixels: cylindrical and Fuller lighting share mutually exclusive scratch space, color-change flags use a bitset, chart symbols keep their pixels in compact row bits, and the callout shares its placement code. The ticker scales the existing font, and the paper/board mixtures are generated while coloring the ground, with no new image buffers. See docs/memory-v0.3.0.json for the measurements.

Every release now requires verified uploads to both Pebble store listings before publishing the GitHub downloads. Missing configuration fails visibly; a manual workflow run can repair an existing release using its original GitHub packages and checksums. Both 0.2.0 store listings have also been brought up to date.
