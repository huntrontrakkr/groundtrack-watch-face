# Groundtrack 0.8.2

- **Settings save without a Home location.** In time zones without a built-in Home preset, new settings now start with Home set to None. Previously, blank custom coordinates could prevent Save from completing.
- **Location errors are visible.** Saving invalid custom coordinates opens the Home section and shows the validation message.

Includes both Groundtrack and Groundtrack Fuller for Pebble Time 2 and Pebble Round 2.
